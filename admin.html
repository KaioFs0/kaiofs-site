Como criar a chave de acesso (uma vez só)
  1. Entre em github.com/settings/personal-access-tokens/new.
  2. Dê um nome (ex.: Painel do site) e escolha a validade.
  3. Em Repository access, marque Only select repositories e escolha o repositório do site.
  4. Em Permissions → Repository permissions → Contents, escolha Read and write.
  5. Clique em Generate token, copie a chave e cole aqui.

A chave só funciona no repositório do site e fica guardada apenas neste aparelho. Não compartilhe com ninguém.
